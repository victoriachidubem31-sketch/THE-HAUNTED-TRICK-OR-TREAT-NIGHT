# Haunted Trick or Treat Night 🎃👻

## Project Overview
Haunted Trick or Treat Night is a beginner-friendly, spooky, and funny interactive project created using Python 🐍. This project lets users experience a fun haunted adventure while going trick-or-treating in a virtual spooky world 🕸️🦇. It’s designed to be easy to play and enjoyable for all ages 🎃👀.

## How to Play
1. Run the Python program 🖥️.
2. Follow the prompts to make choices during your haunted trick-or-treat adventure 🧙‍♀️🍬.
3. Each decision may lead to surprises, funny situations, or spooky encounters 👻💀.
4. Try different choices to see all the possible outcomes and surprises 🎃🕷️!

The game uses simple input/output commands, making it perfect for beginners who want to practice Python programming while having fun 🐍🎮.

## Why I Made This Project
I created this project to combine learning Python with creativity and fun 🎨👻. I wanted to make something that is beginner-friendly, interactive, and seasonal (perfect for Halloween 🎃). It’s a small way to practice coding logic, if-else statements, and user input handling while creating a playful experience for anyone who runs the program 🕸️🦇.

## Tech Used
- Python 🐍 (for all game logic and interactions)
