# THE-HAUNTED-TRICK-OR-TREAT-NIGHT
Enter the haunted streets of Ravenshade! Trick, treat, or get tricked by ghostly riddles and mischievous witches.  Solve riddles, dodge cursed candies, and see if your bravery and wits can survive the ghostly mischief.  Will you earn the highest score, or will the ghosts have the last laugh? 👻💀🎃
